# WoWTok

Аддон для World of Warcraft (клиент Forever, Interface 16001): окно с вертикальной лентой коротких роликов в стиле TikTok. Ленту листают, перетаскивая мышью, ролики можно лайкать, из ленты открывается профиль персонажа.



## Возможности

- `/tiktok` открывает и закрывает окно (также `/тикток`, `/wowtok`). Окно двигается за заголовок, Esc закрывает.
- Перетащи ленту вверх — следующий ролик, вниз — предыдущий. Работают быстрый рывок и колесо мыши.
- Ролик играет со скоростью 12 кадров в секунду со звуком и по кругу. Звук останавливается при листании, в профиле и при закрытии окна.
- Лайки со счётчиком от 100 до 1 000 000 000, лайк двойным кликом по ролику. Лайки сохраняются.
- Кнопка комментариев со счётчиком, но комментарии недоступны: по клику только сообщение.
- Профиль: портрет, имя цветом класса, уровень, раса, класс, гильдия и число лайкнутых роликов.

| Команда | Что делает |
|---|---|
| `/tiktok` | Открыть или закрыть окно |
| `/tiktok jpg` | Кадры из листов JPEG (по умолчанию) |
| `/tiktok blp` | Кадры из листов BLP, для роликов, сделанных с `--format blp` |
| `/tiktok sound` | Выключить или включить звук роликов |

## Установка

Скопируй папку `WoWTok` в `World of Warcraft\_forever_\Interface\AddOns` и перезапусти игру.

## Свои ролики

Игра не умеет проигрывать видео, поэтому ролик превращается в листы кадров (2048×2048, по 32 кадра 256×456) и звук `.ogg`.

Нужны Python 3 с `numpy` и `Pillow` и `ffmpeg`.

```bash
python tools/convert.py ролик1.mp4 ролик2.mp4
```

- Ролики ложатся в `WoWTok/Media/<id>/`, список — в `WoWTok/videos.lua`. Его скрипт пересобирает сам, ролики можно добавлять по одному.
- Если рядом с видео лежит `<имя>.info.json` (формат yt-dlp), из него берутся автор, подпись, лайки и комментарии.
- `--format blp` пишет кадры в родном формате игры (в 3–6 раз тяжелее JPEG), `--format both` — в обоих.
- Удалить ролик: удалить его папку из `WoWTok/Media` и запустить `python tools/convert.py` без аргументов.
- Новые файлы игра видит только после полного перезапуска, `/reload` не хватит.

Ролик весит примерно 1 МБ на 4 секунды.

`tools/pack.py` собирает архивы аддона в папку Downloads.

## Проверка без игры

```bash
python tests/build_test.py
```

Скрипт собирает `tests/out/test.html`: аддон с поддельным API WoW и набором сценариев, Lua выполняется в браузере через fengari. Открой страницу в браузере, результат — последней строкой.

## Важно

Не выкладывай аддон вместе с чужими роликами: видео из TikTok принадлежат их авторам.
